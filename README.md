#  Admin Dashboard

A clean and responsive **Admin Dashboard** frontend designed to display important business information such as users, orders, revenue, products, sales performance, recent activity, and customer orders.

##  Features

-  Responsive Admin Dashboard layout
-  Sidebar navigation
-  Users section
-  Orders section
-  Products section
-  Reports section
-  Settings section
-  Notification indicator
-  Admin profile section
-  Statistics cards
-  Monthly Sales Overview
-  Year selection dropdown
-  Recent Activity section
-  Recent Orders table
-  Completed order status
-  Pending order status
-  Cancelled order status
-  Responsive design
-  Logout button

##  Dashboard Sections

### 1. Sidebar

The sidebar contains the main navigation options:

- Dashboard
- Users
- Orders
- Products
- Reports
- Settings
- Logout

The dashboard uses **AdminPanel** as the application logo.

### 2. Header

The header contains:

- Mobile menu button
- Dashboard title
- Welcome message
- Notification icon
- Notification count
- Admin profile

The current profile displays **Krishnakant – Admin**.

### 3. Statistics Cards

The dashboard displays four main statistics:

| Statistic      |   Value |  Growth |
| -------------- | ------: | ------: |
| Total Users    |   1,250 | ↑ 12.5% |
| Total Orders   |     450 |  ↑ 8.2% |
| Total Revenue  | ₹85,000 | ↑ 15.3% |
| Total Products |     320 |  ↑ 5.4% |

These cards provide a quick overview of the platform's performance.

### 4. Sales Overview

The Sales Overview section displays monthly sales performance using a bar chart.

Available years:

- 2026
- 2025
- 2024

The chart currently displays monthly data from **January to August**.

### 5. Recent Activity

The Recent Activity section shows the latest platform updates, including:

- New user registration
- New order received
- Payment received
- Product added

Each activity includes a description and timestamp.

### 6. Recent Orders

The Recent Orders section contains a responsive table with:

- Order ID
- Customer
- Product
- Date
- Amount
- Status

Example statuses include **Completed, Pending, and Cancelled**.

## ⚙️ How to Run

1. Clone or download the project.
2. Open the project folder.
3. Make sure `index.html`, `style.css`, and `script.js` are in the correct locations.
4. Open `index.html` in your browser.

For the best development experience, you can use **VS Code with Live Server**.
