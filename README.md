#  TravelGo – Travel & Tourism Website

TravelGo is a modern and responsive **Travel & Tourism website** designed to help users explore popular destinations, view travel services, check tour packages, and submit a booking request.

The website provides a clean and user-friendly interface for discovering destinations and planning memorable trips.

---

##  Features

-  **Home / Hero Section**

  - Attractive travel banner
  - "Explore The World, One Journey At A Time" heading
  - Explore Now call-to-action button

-  **Popular Destinations**

  - Delhi
  - Manali
  - Goa
  - Kashmir

-  **Travel Services**

  - Hotel Booking
  - Flight Booking
  - Car Rental
  - Tour Packages

-  **Popular Tour Packages**

  - Goa Beach Escape
  - Manali Adventure
  - Golden Triangle

-  **About TravelGo**

  - Company introduction
  - Experience and traveler statistics
  - Destination information

-  **Booking / Contact Form**

  - Full Name
  - Email
  - Destination
  - Travel Date
  - Message
  - Booking Request button

-  **Login Page**

  - Navigation to a separate login page

-  **Responsive Navigation**

  - Mobile menu button
  - Navigation links for different sections

-  **Footer**

  - Quick links
  - Destinations
  - Social media links
  - Copyright information

---

## Technologies Used

- **HTML5** – Website structure and semantic elements
- **CSS3** – Styling, layout, animations and responsive design
- **JavaScript** – Interactivity and form/menu functionality
- **Unsplash** – Travel destination images

##  Website Sections

### 1. Navbar

The navigation bar contains the TravelGo logo and links to:

- Home
- Destinations
- Services
- About
- Contact
- Login

The navigation also includes a mobile menu button for smaller screens.

### 2. Hero Section

The hero section introduces the TravelGo website with the message:

> **Explore The World, One Journey At A Time**

It also provides an **Explore Now** button that takes users to the destinations section.

### 3. Destinations

The website currently showcases four popular destinations:

| Destination | Description                         |
| ----------- | ----------------------------------- |
| 🇮🇳 Delhi  | History, culture and delicious food |
|  Manali     | Mountains, snow and adventure       |
|  Goa        | Beaches, nightlife and culture      |
|   Kashmir   | Mountains, lakes and scenic beauty  |



### 4. Services

TravelGo provides four main services:

- **Hotel Booking**
- **Flight Booking**
- **Car Rental**
- **Tour Packages**

These services are designed to make travel comfortable and convenient.

### 5. Tour Packages

The website provides three featured packages:

| Package          |          Duration |   Price |
| ---------------- | ----------------: | ------: |
| Goa Beach Escape | 4 Days / 3 Nights | ₹14,999 |
| Manali Adventure | 5 Days / 4 Nights | ₹18,999 |
| Golden Triangle  | 5 Days / 4 Nights | ₹16,999 |



### 6. About Section

The About section describes TravelGo as a travel company focused on helping travelers discover amazing destinations.

The website highlights:

- **10+ Years Experience**
- **50K+ Happy Travelers**
- **100+ Destinations**



### 7. Booking Form

Users can submit their travel requirements through the booking form.

The form collects:

- Full Name
- Email
- Destination
- Travel Date
- Message

The available destinations in the form are Delhi, Manali, Goa and Kashmir.

## ⚙️ How to Run the Project

### Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/travelgo.git
```

### Step 2: Open the Project

```bash
cd travelgo
```

### Step 3: Run the Website

Open `index.html` directly in your browser.

For the best development experience, you can use **VS Code with the Live Server extension**.
