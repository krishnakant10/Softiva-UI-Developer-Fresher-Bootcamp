Softiva UI Developer Fresher Bootcamp (Self-Learning + Review Model)
Program Objective
Train a fresher to become a production-ready UI developer capable of contributing to Softiva products such as Lekha, AI dashboards, JBN Horizon, and .NET Web API-based applications.
Duration: 6 Weeks
Commitment: 6 Hours/Day (Monday-Saturday)
Total Learning Hours: 216 Hours
Training Model: Self-learning with structured milestones and mentor reviews
Learning Methodology
The trainee is expected to:
Study assigned resources independently
Build all assigned features and projects
Push code to GitHub daily
Create a Pull Request (PR) for every assignment
Maintain a learning journal (Notion or Markdown)
The Senior UI Developer will:
Review code during scheduled internal reviews
Conduct architecture and code-quality discussions
Provide improvement tasks
Approve progression to the next module
Daily Schedule (6 Hours)
Time	Activity
09:00-10:30	Self-study (videos/documentation)
10:30-12:30	Hands-on implementation
12:30-13:00	Break
13:00-14:30	Assignment / feature development
14:30-15:00	Git commit, PR creation, documentation update
Every day must end with:
Git Commit
GitHub Push
Pull Request
Learning Journal Entry
