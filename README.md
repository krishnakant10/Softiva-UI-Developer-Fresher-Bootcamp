Softiva UI Developer Fresher Bootcamp


 Overview

This repository contains my work and learning progress during the Softiva UI Developer Fresher Bootcamp.

The bootcamp focuses on developing production-ready UI development skills using modern frontend technologies, including HTML, CSS, JavaScript, TypeScript, React, Tailwind CSS, APIs, state management, Git, testing, and deployment.

The program follows a self-learning + mentor review model where assignments and projects are completed regularly and submitted through GitHub Pull Requests.




🎯 Objectives

The main objectives of this bootcamp are:

Build responsive and modern user interfaces
Learn component-based development with React
Write clean and maintainable TypeScript code
Work with REST APIs
Implement forms and validation
Manage application state
Follow professional Git and GitHub workflows
Perform basic frontend testing
Deploy applications
Build production-quality frontend applications
